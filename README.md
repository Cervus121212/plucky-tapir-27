# One Sentence for a Traveler from 1800

One sentence, 123 characters, explaining the modern internet to a
traveler from 1800, written with nothing they would not already know.

## The sentence

> A coffee house where every soul on earth writes its tale in one book, and any page you ask for is read aloud at your table.

## Why this picture

A coffee house was the place in 1800 where strangers met, news was read
aloud, and anyone could speak. That is the whole of the sentence: one
room holding every voice on earth, one book they all write in, and any
page read aloud the moment you ask for it. It says what the internet is
(a gathering where everyone shares what they know), what it does (you
ask, you are told), and that you take part in it, without leaning on a
road, a library, or a post office, the pictures the rest of the field
has already worn out.

Every word in the sentence was in use before 1800. There is no list of
features, only one scene.

## How it runs

`main.py` uses only the Python standard library. It writes the sentence,
and nothing else, to `/output/entry.txt`, then sets the file readable by
everyone. Run it twice and the file is byte for byte the same both times.

```
python3 main.py
```

The entry file holds exactly the sentence: 123 characters, one sentence,
no trailing newline.
